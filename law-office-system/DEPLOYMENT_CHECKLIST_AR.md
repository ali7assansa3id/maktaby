# قائمة تحقق قبل التشغيل الفعلي

- [ ] إنشاء مشروع Supabase منفصل للتجربة.
- [ ] تنفيذ schema.sql ومراجعة كل سياسات RLS.
- [ ] تحديد سياسة وصول: مكتب واحد مشترك أم عدة مكاتب/فرق معزولة.
- [ ] إضافة صلاحيات حقيقية للأدوار (admin / lawyer / assistant / viewer) على مستوى قاعدة البيانات.
- [ ] منع التسجيل العام أو ضبط الدعوات حسب سياسة المكتب.
- [ ] اختبار حساب غير مسجل، ومستخدم عادي، ومساعد، ومدير.
- [ ] اختبار الحذف والتعديل ومحاولات الوصول إلى سجلات غير مصرح بها.
- [ ] إعداد نسخ احتياطية دورية وتجربة الاستعادة.
- [ ] إعداد إجراء لاستعادة كلمة المرور.
- [ ] تحديد سياسة الاحتفاظ بملفات الموكلين والبيانات الحساسة.
- [ ] استخدام HTTPS ونشر الموقع من مصدر موثوق.
- [ ] لا تستخدم بيانات قضايا حقيقية قبل مراجعة أمنية وقانونية مناسبة.
